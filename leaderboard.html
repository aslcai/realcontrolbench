RealControlBench: Fine-Grained Control of LLMs and Agents

RealControlBench evaluates activation steering in language models and agents. This site presents instruction-following, tool-use, and reasoning evaluations, measuring both behavioral control and task performance.

Submit a method

Submit your method and configuration. We run the benchmark and publish the evaluated results.

  1. 01

    Prepare your method

    Provide runnable method code, the base model, target tasks, and configuration. Include any required steering vectors or other artifacts.

  2. 02

    Submit a pull request

    Fork the benchmark repository and add your method. Include installation instructions, a run command, and your contact information in the PR.

  3. 03

    We run the evaluation

    We review the implementation, run the benchmark, and add the evaluated results to the leaderboard.

You do not need to submit evaluation results or logs.
